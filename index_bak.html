01. JAVIS - Trouble Shooting

문제점
좁은 통로 및 복잡한 환경 주행 테스트 시:
• Inflation 딜레마: 안전 마진을 높이면 좁은 길 진입 실패 및 Recovery Loop 발생, 낮추면 벽면 충돌 위험 증가
• 기구학적 충돌: 직사각형 차동 로봇이 장애물이나 협소한 공간에 있을때 빠져나오지 못하거나 그로 인해 회복 동작(Rotate/costmap reset) 중 장애물과 빈번한 충돌 발생
문제 분석
• 기구학적 불일치: NavFn이 로봇의 실제 크기를 무시한 '점 모델' 경로를 생성하여 차동 로봇이 추종하기 힘든 경로 발생
• 센서 인지 사각지대: LiDAR 필터링 범위가 실제 로봇 모델보다 넓게 설정되어, 코앞의 장애물을 노이즈로 판단해 무시해 rotate나 costmap 초기화 시 충돌 되는 현상을 확인
• 제어 알고리즘 제약: DWB의 단순 속도 샘플링 방식이 복잡한 환경에서 유효한 회피 궤적을 찾지 못하고 주행이 정체되는 한계 분석
해결방안
• Smac Planner Hybrid 도입: 로봇 형상(Footprint)과 회전 반경을 반영해 물리적으로 실행 가능한 경로 및 페널티 기반의 중앙 주행 유도
• 센서/cost 최적화: LiDAR 필터 범위 재설계 및 코스트맵 가중치 튜닝으로 중앙 주행 유도
• MPPI Controller 전환: 샘플링 기반 모델 예측 제어를 통해 장애물 밀집 구간에서의 부드러운 속도 조절 및 주행 유연성 향상

02. ROOMIE - Truble Shooting

Jerk & Vibration
Problem
저가형 서보모터 특성상 동작 시작/정지 시 저가형 서보모터/프레임으로 인해 떨림 발생, 버튼 타격 시 정확도 저하와 기어 마모 문제 유발
Solution
• S-Curve Profiling: 여러가지 프로파일 테스트 시 가장 떨림이 적은 가우시안 형태의 S-Curve 속도 프로파일을 적용하여 가/감속 충격 완화
• Result: 잔진동을 40% 이상 제거하고 기어 마모 방지 향상
Visual Servoing & Calibration
Problem
카메라와 로봇 베이스 간의 물리적 위치 오차(Extrinsic Parameter) 및 렌즈 왜곡으로 인해, 픽셀 좌표를 기반으로 계산된 목표 지점과 실제 로봇 암의 타격 지점이 일치하지 않는 현상 발생.
Solution
• Hand-Eye Calibration: 로봇 베이스 좌표계와 카메라 좌표계 사이의 변환 행렬을 정밀하게 산출하여 좌표계를 통합.
• Visual Servoing (Closed-loop): 단발성 이동(Open-loop)이 아닌, 카메라 피드백을 통해 목표 버튼과 엔드 이펙터 사이의 오차($e$)를 실시간으로 계산하고 보정하는 피드백 제어 루프 구현.
• Result: 환경 변화에 유연하게 대응하며 버튼 조작 성공률을 대폭 향상.

03. FALCON - Technical Challenges

2D to 3D Accuracy
Problem
CCTV 화면(2D 픽셀)만으로는 활주로 내 객체의 실제 거리와 정확한 GPS 좌표를 파악할 수 없어 관제 데이터로 활용 불가.
Solution
• Homography: 활주로 4개 지점 ArUco 마커를 기준점으로 투영 변환 행렬 산출
• Result: 픽셀 좌표를 실제 미터(Meter) 단위로 변환, 오차 범위 ±0.5cm 정밀도 확보
Data Scarcity
Problem
보안 구역인 활주로에 실제 이물질(FOD)을 뿌리거나 침입 상황을 연출하여 학습 데이터를 수집하는 것이 현실적으로 불가능.
Solution
• Synthetic Data: Blender 3D 툴로 다양한 기상(비/안개), 조도 환경의 가상 데이터를 생성
• Result: 가상 데이터 학습 모델을 실제 환경에 적용 시 90% 이상의 높은 검출률 달성
